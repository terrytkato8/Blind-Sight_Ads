# Contributor IP Assignment — Term Sheet

Everyone who has contributed code, art, audio, design or writing to Blind Sight signs a short assignment based on these terms. The studio has to own the game's IP outright before it can license branded assets to sponsors. *Non-binding term sheet; the final agreement is drafted by counsel.*

| Term | Position |
| --- | --- |
| Parties | Kato.8 Studios LLC, a California limited liability company ("Studio"), and [Contributor name] ("Contributor") |
| Project | Blind Sight, an asymmetric multiplayer horror-comedy game in Unreal Engine, including all builds, maps, marketing materials, sponsor integrations and future updates ("Game") |
| Assignment | Contributor assigns to Studio all rights, title and interest in all work product created for the Game (code, Blueprints, 3D models, textures, animations, audio, MetaSounds, level designs, UI, writing and design documents) |
| Effective date | Retroactive to the Contributor's first contribution, [start date], and covering all future contributions |
| Work made for hire | To the extent the law allows, the work is "work made for hire." Anything that doesn't qualify is assigned |
| Pre-existing IP | Contributor lists any prior tools, code or assets in Exhibit A. If used in the Game, Contributor grants Studio a perpetual, royalty-free, worldwide license to use them in the Game |
| Third-party and AI content | Contributor confirms the work is original or properly licensed. Marketplace assets, open-source code and AI-generated content must be disclosed and logged before they are committed |
| Sponsor content | Contributor gets no rights in sponsor trademarks or brand assets, and keeps sponsor deal terms confidential |
| Moral rights | Contributor waives moral rights (or agrees not to assert them) so Studio can modify, restyle and remove assets, including sponsor-branded versions |
| Compensation | As set out in the Contributor's Revenue Share Agreement. Sponsorship revenue is shared through the bonus provision in that agreement, Section [__] |
| Credit | Name in the Game's credits and on the Steam page credits, in the role agreed |
| Portfolio rights | Contributor may show their own work in a personal portfolio after the Game's public release. Unreleased content and confidential sponsor terms are excluded |
| Confidentiality | Unreleased game content, builds, sales pipeline and sponsor terms stay confidential during and after the engagement |
| Further assurances | Contributor signs any further documents needed to record or enforce the assignment |
| California notice | Includes the Labor Code §2870 notice: inventions developed entirely on the Contributor's own time, without Studio resources and unrelated to the Game, are excluded |
| Relationship | Independent contractor. Counsel should review classification under California's AB5 test for revenue-share contributors |
| Governing law | California; venue in Los Angeles County |

## Collection checklist

- [ ] Pull the full list of past and current contributors from the repository history and asset logs
- [ ] Send the assignment with each contributor's Exhibit A (pre-existing IP) to fill in
- [ ] Log every third-party, marketplace or AI-generated asset with its license
- [ ] Store signed copies in the contracts folder and mark each person as signed in the tracker
- [ ] Don't merge new work from anyone who hasn't signed
